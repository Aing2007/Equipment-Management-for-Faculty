# Equipment-Management-for-Faculty
โครงการย่อสำหรับวิชา "Form Dev to the moon"

## ภาพรวมของโปรเจกต์
โปรเจกต์นี้เป็นแอปพลิเคชันเว็บแบบ full-stack ที่ใช้สำหรับจัดการอุปกรณ์ของคณะ ผู้ใช้สามารถดูข้อมูลอุปกรณ์และเพิ่มอุปกรณ์ใหม่ได้ ส่วน backend จะให้ API สำหรับอ่านและเพิ่มข้อมูลอุปกรณ์

## โครงสร้างของไฟล์
- `front/` - เก็บไฟล์หน้าเว็บ (HTML, CSS, JavaScript) สำหรับแสดงหน้าจอและติดต่อกับ API
- `EMF/` - โฟลเดอร์หลักของ Backend/System สำหรับจัดการข้อมูลอุปกรณ์และห้องต่าง ๆ ผ่าน API
- `README.md` - เอกสารอธิบายโปรเจกต์

## ความรับผิดชอบของแต่ละส่วน
### `front/`
- `index.html` แสดงโครงสร้างหน้าเว็บ
- `style.css` จัดการรูปแบบการออกแบบและการตอบสนองของหน้าเว็บ
- `app.js` รับข้อมูลจาก backend และอัปเดตหน้าเว็บ

### `EMF/`
`EMF` เป็นส่วน Backend ของโปรเจกต์ที่ทำหน้าที่จัดการข้อมูลหลักของระบบ เช่น
- ลงทะเบียนและเข้าสู่ระบบของผู้ใช้
- ตรวจสอบสิทธิ์การเข้าถึง (JWT + Role)
- ดู เพิ่ม แก้ไข และลบข้อมูลอุปกรณ์
- ดู เพิ่ม แก้ไข และลบข้อมูลห้อง
- เชื่อมต่อกับ MongoDB เพื่อเก็บข้อมูลแบบเรียลไทม์

โครงสร้างภายใน `EMF/` ประกอบด้วย:
- `server.js` - เริ่มต้น Express Server และติดตั้ง route หลัก
- `config/db.js` - เชื่อมต่อฐานข้อมูล MongoDB
- `routes/` - กำหนด API endpoints สำหรับ auth, equipments, rooms
- `controllers/` - ประมวลผล logic ของแต่ละฟังก์ชัน
- `models/` - กำหนดโครงสร้างข้อมูลใน MongoDB
- `middleware/auth.js` - ตรวจสอบ token และสิทธิ์ผู้ใช้
- `seeder.js` - เพิ่มข้อมูลตัวอย่างเพื่อทดสอบระบบ
- `package.json` - กำหนด dependency และข้อมูลโปรเจกต์

### `backend/`
- `server.js` เริ่มต้น Express Server, ให้บริการไฟล์ frontend และมี route สำหรับ API
- `package.json` กำหนด script และ dependency ของโปรเจกต์

## ข้อกำหนดเบื้องต้น
- ติดตั้ง Node.js แล้ว
- ติดตั้ง npm ที่มากับ Node.js แล้ว

## วิธีเริ่มต้นใช้งานโปรเจกต์
1. เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์
2. เข้าไปที่โฟลเดอร์ backend:

```bash
cd backend
```

3. ติดตั้ง dependencies:

```bash
npm install
```

4. เริ่มต้นโปรเจกต์:

```bash
npm start
```

5. เปิดเบราว์เซอร์แล้วไปที่:

```text
http://localhost:3000
```

## API ที่มีให้ใช้งาน
backend มี route ดังนี้:

- `GET /api/health` - ตรวจสอบว่า API ทำงานได้ปกติ
- `GET /api/equipment` - ดึงข้อมูลอุปกรณ์ทั้งหมด
- `GET /api/equipment/:id` - ดึงข้อมูลอุปกรณ์ตาม ID
- `POST /api/equipment` - เพิ่มอุปกรณ์ใหม่
